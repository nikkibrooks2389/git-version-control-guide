Git & Version Control Guide

Understand what changed, record meaningful versions, and share work when you are ready. Begin locally, then choose where your repositories live.

Git is the tool. Hosting is a choice.

Git records history on your computer. GitHub, GitLab, Bitbucket, Azure Repos, Codeberg, and self-managed servers are possible places to share a Git repository. You can use Git with no online host at all. GitHub appears here as one worked example, not as a requirement.

On your computer

Edit, inspect, stage, commit, and read history offline.

At a remote

Exchange committed history with another repository location.

On a live website

Deploy selected files through a separate hosting workflow.

How to use this guide

Follow the numbered lessons in order, or use Quick Reference for reminders. A small my-website repository connects the examples. Each lesson explains prerequisites, shows commands and their expected effects, links original documentation, and ends with hidden-answer study questions. You can read everything offline except external source links.

Explanations are original. Git’s official documentation is the main command reference; platform documentation explains the features specific to each host. Browse all sources.

Study questions

Explain it in your own words, then open the answer.

Do I need GitHub to begin?

No. Start Here records local versions without an online account.

Is this a terminal I can type commands into?

No. It is a reading guide. Use your own terminal in a separate learning repository.

Will pushing necessarily publish a website?

No. A deployment must be configured separately.
