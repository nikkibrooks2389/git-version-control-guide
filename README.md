# Git & Version Control Guide

A standalone beginner learning website covering local Git, repository hosting alternatives, collaboration, recovery, and website publishing.

Open `index.html` in a browser. No installation, JavaScript, or build step is required to read the guide. Commands are static educational examples, not an embedded terminal.

## Contents

- First saved version walkthrough
- Ten numbered topic lessons
- Quick reference and glossary
- Official source library

GitHub is one example host; GitLab, Bitbucket, Azure Repos, Codeberg, local repositories, and self-managed hosting are explained separately.

All pages use `css/styles.css`, adapted from the companion HTML guide. Each lesson includes a reference table, contextual examples, source links, navigation, and expandable study answers.

To serve locally, run `python3 -m http.server 8000` from this folder and visit http://localhost:8000. Direct file opening also works.

This is a separate project from html-guide.
